## 环境踩坑
- 项目 `.venv` 为 Python 3.13.12 (x86_64),初始无 cv2/matplotlib。
- `pip install opencv-python matplotlib` 一次性装会报 "PACKAGES DO NOT MATCH THE HASHES",需 `--no-cache-dir --no-deps` 逐个安装。
- opencv 需固定 `opencv-python==4.10.0.84`(最新 5.1.0.95 只有 sdist,本机编译失败)。
- 安装过程中偶发 sandbox shim Segmentation fault,重试即可;最终确认可用版本:opencv 4.10.0 / matplotlib 3.11.2 / numpy 2.5.5。
