## 新增课件 06translate.py（补上 11-13 留空的编号）
- `2图像绘制与变换/06translate.py`：`M = np.float64([[1, 0, 100], [0, 1, 50]])` 手工构造 2x3 平移矩阵（第三列 = 平移量，x 右移 100、y 下移 50），再 `cv2.warpAffine(img, M, (width, height))`。已加 `os.chdir(__file__ 所在目录)`。
- 实测：img.shape (330,333,3)；M dtype float64、shape (2,3)；结果 shape (333,330,3)，即 dsize 传反导致宽高互换（宽 330 比原图 333 少 3px、高 333 多 3px，多出的部分是黑边）。用正确 dsize (333,330) 则结果回到 (330,333,3)。
- 视觉核对：猫整体右移下移，左侧 100px、上方 50px 出现黑边，右/下被裁掉。
- 与 07rotate.py 的关系：同一套 warpAffine，矩阵来源不同（手工构造 vs getRotationMatrix2D）；平移矩阵第三列就是偏移量，反方向平移把 100/50 改成负数。
- 课件写法 `width, height = img.shape[:2]` 依旧把高宽搞反（这是第二处），近正方形图看不出来。

## 新增课件 08radiate.py
- `2图像绘制与变换/08radiate.py`：`cv2.getAffineTransform(pst1, pst2)` 由 3 组点对求 2x3 仿射矩阵，再 `warpAffine` 输出。已加 `os.chdir`。
- 实测矩阵 `M = [[-1, 0, 200], [0, 1, 0]]`，即 `x' = -x + 200, y' = y` → 关于 **x=100 的垂直轴水平镜像**。三点映射结果与 pst2 完全吻合：[[190,10],[180,20],[150,30]]。
- 副作用：原图宽 333，x>200 的点映射到负坐标被裁掉，所以结果只有左侧 200px 内容，右侧 130px 全黑。若要做完整水平翻转，正确矩阵是 `[[-1,0,W-1],[0,1,0]]`（W=333 时 x'=332-x，0→332 不越界）。
- 第三处 `width, height = img.shape[:2]` 倒置 + dsize 传反，结果 shape 仍为 (333,330,3)。
- 课件变量名 `img_radiate`、文件名 radiate 实际语义是镜像/仿射，命名不准确，照课件保留。
