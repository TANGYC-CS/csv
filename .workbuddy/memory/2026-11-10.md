## OpenCV 3.4.2 环境部署（按课程课件要求）

- 课件要求 `opencv-python==3.4.2.16`，但 PyPI 上 3.4.2 系列只有 `3.4.2.17`（对应 OpenCV 3.4.2），3.4.2.16 不存在，属课件笔误。
- 该版本 wheel 最高仅支持 cp37，无法装进系统自带的 Python 3.11 / 3.13。
- 解决方案：在项目目录独立安装 Python 3.7.9，不动系统 Python。
  - 解释器：`F:\计算机视觉\Python37\python.exe`（3.7.9，pip 20.1.1）
  - numpy 1.19.5、matplotlib 3.5.3（3.7 的兼容版本）
  - opencv-python 3.4.2.17 + opencv-contrib-python 3.4.2.17（contrib 后装覆盖，含非免费算法）
- 验证结果：`cv2.__version__ == 3.4.2`，`cv2.xfeatures2d.SURF_create` / `SIFT_create` 均可用（专利算法正是选旧版的原因）。
- 注意：3.4.x 中 SIFT 需用 `cv2.xfeatures2d.SIFT_create()`，没有顶层 `cv2.SIFT_create`（4.4+ 才有）。
- 已删除临时安装包，目录只保留 `Python37`。

## OpenCV 保存图片脚本（2026-11-12）

- 新建 `F:\计算机视觉\1图像处理\06opencv_save_cat.py`：课件 `06opencv_save.py` 的 cat.png 版，`imread` 后直接 `imwrite`。因 imread/imwrite 同为 BGR，无需 cvtColor。
- 验证：`imwrite` 返回 True，存出的 png 与原图 `np.array_equal` 完全一致。
- 验证坑点：目标目录不存在时 `imwrite` 只返回 False、不抛异常也不建目录，必须用返回值判断或用 `os.makedirs` 先建。
